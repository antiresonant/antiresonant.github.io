Kathmandu Ward Map

Loading OSM wards

This interactive Kathmandu ward map helps people find ward numbers and boundaries inside Kathmandu Metropolitan City, also called KMC or Kathmandu Mahanagarpalika. It combines a real street map, satellite view, OpenStreetMap ward polygons, and an official-style ward raster overlay so the ward map can be read against actual roads and places.

Use it when you need to identify a Kathmandu ward for forms, local address lookup, ward office questions, planning work, school or research projects, property context, or general navigation across Kathmandu, Nepal.

What is included

  • Ward number lookup for Kathmandu Metropolitan City wards 1-32.
  • Overlay of Kathmandu ward boundaries on current street and satellite maps.
  • Opacity control for comparing the ward raster with real roads.
  • Ward selector for zooming to available KMC ward boundary polygons.
  • Local GeoJSON data for faster loading and more reliable access.

Kathmandu wards covered

The raster layer shows all 32 Kathmandu wards. The vector layer uses available OpenStreetMap ward relations and currently includes 29 KMC ward polygons; wards 22, 24, and 25 remain visible in the raster layer.
